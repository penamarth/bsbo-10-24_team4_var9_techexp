#Диаграмма прецедентов Техническая экспертиза

```
@startuml
skinparam packageStyle rectangle
skinparam ranksep 20
skinparam nodesep 10

actor "Независимый эксперт" as Expert

rectangle "Информационная система «дайденег.систем»" {
  usecase "Авторизоваться / Войти в личный кабинет" as UC_Auth
  usecase "Провести техническую экспертизу" as UC_Review
  usecase "Выставить оценки по критериям 0-10" as UC_Scores
}

Expert -> UC_Auth
UC_Auth .right.> UC_Review : <<extend>>
UC_Review .right.> UC_Scores : <<include>>

@endum
```
