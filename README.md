## Вариант

9.Информационная система технической экспертизы
Обзор: информационная система технической экспертизы позволяет соискателям грантов подавать заявки, независимым экспертам оценивать
заявки, а держателям фонда принимать решение о выдаче гратов по результатам экспертизы заявок.



Пример: https://gitlab.com/penamarth/pos.git
